Module trait (`module.rs`) is `Send + Sync`, key/label/detect/cost — matches the
plan's design and is **not** `dyn`-dispatched per-module (static OnceLock map).

## 3. Performance strategy — baselines + remaining

### Current (verified Aug 2026)

- Cold start full fetch: **686 ms** (network-bound) / **242 ms** with publicip cache.
- `--minimal` perf-gate: **< 10 ms mean** (hyperfine, 50 runs, CI fails above).
- Binary: minimal **1.53 MB**, release **2.02 MB**, full **6.33 MB**.
- Zero-spawn collectors: kernel/packages/wm/disk/health/network/wifi/publicip/cpuusage (Phase 4.1).

## 12. How to execute this plan

1. **One ticket per table row** above, marked with its feature gate.
2. Each ticket is independently deployable; no WIP accumulation.
3. After each feature: bump version in `Cargo.toml`, commit, tag `vX.Y.Z`,
   `git push --tags` (project convention).
4. Verify after every task: `cargo test --workspace`, `cargo clippy -- -D warnings`,
   `cargo fmt --check`, feature-off build (`--no-default-features`), hyperfine gate.
5. Rejected-list items (ROADMAP "Rejected/decisions") are off-limits without new
   justification.
