What it does

Everything a fetch should be. Nothing it shouldn't.

Core modules read the system directly: /proc, sysfs, or macOS APIs. A few optional ones shell out to a platform tool only when needed.

Reads the system directly

Most collectors read /proc, sysfs, or macOS APIs directly; the cpu module typically finishes in under a millisecond. A few optional modules (wifi, bluetooth, media, wallpaper, git) shell out to the platform tool only when needed.

Get it

On your machine in one command.

Releases ship Linux (musl static, 3 arches) and macOS (arm64 + x86_64) binaries. Every release ships SHA-256 checksums and cosign signatures. The installer verifies the checksum before unpacking and aborts on a mismatch (verification needs a sha256sum/shasum tool; without one, the installer refuses to run).

  • SHA-256 verifiedthe installer aborts on a checksum mismatch
  • cosign-signedbinaries verifiable with the release key
  • Build provenanceCycloneDX SBOM generated by the release pipeline
curl installer official
$ curl -fsSL https://github.com/mahesh-diwan/flexfetch/releases/latest/download/install.sh | sh

Detects your platform, verifies the SHA-256 checksum, and aborts on any mismatch or missing checksum tool.
