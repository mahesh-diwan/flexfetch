Not a binary. A platform.

Extend flexfetch without forking it. Three tiers of extensibility, all auto-loaded from your plugins directory.

Lua plugins

Drop a .lua file into ~/.config/flexfetch/plugins/ and it becomes a module on the next run. Full access to the render context.

  • one file = one module
  • read files, run commands, emit values
  • zero recompiles

WASM sandbox

Compile a plugin to WebAssembly and flexfetch runs it with resource limits inside an isolated sandbox. Memory-safe by construction.

  • execution time and memory limits
  • no host imports unless granted
  • structured data exchange between plugin and host

Signed registry

flexfetch plugin search|install|list|update against a TOML registry. Every entry is cryptographically signed before the checksum is verified.

  • version compatibility check
  • publisher CLI: registry_sign
  • refuses to install anything that fails verification
