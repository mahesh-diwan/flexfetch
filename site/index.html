Everything a fetch should be — and nothing it shouldn't.

Every module is a direct read: /proc, sysfs, the Windows registry or macOS APIs. No subprocess spawns, no parsing of your neighbor's output, no startup cost.

⚡

Sub-10 ms cold start

Zero subprocess spawns. Each collector reads kernel data directly, and a CI perf gate (hyperfine, 50 runs) fails the build if the mean ever drifts past 10 ms.

🎨

Themes & gradients

Built-in presets (Catppuccin, Dracula, Nord, Solarized, Tokyo Night…), truecolor everywhere, per-module key/value colors, and gradient accents. Or roll your own.

🖥️

ASCII & image logos

527 distro logos imported from fastfetch, plus PNG/BMP logos rendered as block characters with automatic palette extraction from your wallpaper.

📈

Live dashboard

flexfetch --live opens a TUI with CPU/memory/disk gauges, per-process bars, network sparklines.

🔌

Lua & WASM plugins

Write a custom module in Lua in five minutes, or ship memory-safe WebAssembly plugins that run fuel-limited inside a sandbox. Auto-loaded from ~/.config/flexfetch/plugins/.

🔒

Supply-chain hardened

Plugins install via an Ed25519-signed registry with SHA-256 verification. Releases carry cosign signatures, CycloneDX SBOMs and SLSA provenance.

Not a binary. A platform.

Extend flexfetch without forking it. Three tiers of extensibility, all auto-loaded from your plugins directory.

Lua plugins

Drop a .lua file into ~/.config/flexfetch/plugins/ and it becomes a module on the next run. Full access to the render context.

  • one file = one module
  • read files, run commands, emit values
  • zero recompiles

WASM sandbox

Compile a plugin to WebAssembly and flexfetch runs it fuel-limited inside a wasmtime sandbox. Memory-safe by construction.

  • fuel metering kills runaway loops
  • no host imports unless granted
  • strict JSON ABI for values

Signed registry

flexfetch plugin search|install|list|update against a TOML registry. Every entry verified with Ed25519 before the SHA-256 download check.

  • min_flexfetch_version gating
  • publisher CLI: registry_sign
  • fail-closed on any tamper
