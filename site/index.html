Your whole system.
Fetched in milliseconds.

flexfetch is a blazing-fast, themeable system info tool for Linux and macOS. 38 modules, 527 logos, and a live TUI dashboard. Zero subprocesses, pure Rust.

Everything a fetch should be. Nothing it shouldn't.

Every module reads the system directly: /proc, sysfs, or macOS APIs. No subprocesses, no parsing, no startup cost.

⚡

Fast

Each collector reads kernel data directly. No subprocess spawns, no parsing overhead. Warm runs complete in milliseconds.

🎨

Themes & gradients

Built-in presets (Catppuccin, Dracula, Nord, Solarized, Tokyo Night…), truecolor everywhere, per-module key/value colors, and gradient accents. Or roll your own.

🖥️

ASCII & image logos

527 distro logos imported from fastfetch, plus PNG/BMP logos rendered as block characters with automatic palette extraction from your wallpaper.

📈

Live dashboard

flexfetch --live opens a TUI with CPU/memory/disk gauges, per-process bars, network sparklines.

🔌

Lua & WASM plugins

Write a custom module in Lua in five minutes, or ship memory-safe WebAssembly plugins that run with resource limits inside a sandbox. Auto-loaded from ~/.config/flexfetch/plugins/.

🔒

Supply-chain hardened

Plugins install via a signed registry with checksum verification. Every entry is cryptographically verified before execution. Releases carry signatures and provenance attestations.

On your machine in one command.

Releases ship Linux (musl static, 3 arches) and macOS (arm64 + x86_64) binaries. Every artifact includes checksums and signatures for verification.
