Everything a fetch should be. Nothing it shouldn't.

Every module reads the system directly: /proc, sysfs, or macOS APIs. No subprocesses, no parsing, no startup cost.

✓

Zero subprocesses

Every collector reads kernel data directly. No forking, no parsing overhead. Warm runs complete in milliseconds.

✓

Themes & gradients

Built-in presets (Catppuccin, Dracula, Nord, Solarized, Tokyo Night), truecolor everywhere, per-module key/value colors, gradient accents.

✓

ASCII & image logos

527 distro logos imported from fastfetch, plus PNG/BMP logos rendered as block characters with automatic palette extraction.

✓

Live TUI dashboard

flexfetch --live opens a TUI with CPU/memory/disk gauges, per-process bars, network sparklines.

✓

Lua & WASM plugins

Write a custom module in Lua in five minutes, or ship memory-safe WebAssembly plugins that run with resource limits inside a sandbox.

✓

Supply-chain hardened

Plugins install via a signed registry with checksum verification. Every entry is cryptographically verified before execution.

On your machine in one command.

Releases ship Linux (musl static, 3 arches) and macOS (arm64 + x86_64) binaries. Every artifact includes checksums and signatures for verification.
