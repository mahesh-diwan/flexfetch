Your system, watching you back.

flexfetch --live turns the fetch into a real-time TUI with gauges, sparklines, and top processes.

Real-time gauges

CPU and memory move in live as you work. All zero-subprocess collectors, so the dashboard itself costs almost nothing.

Top processes

PID, command and per-process CPU/memory bars with live sorting. An htop-lite built on the same module engine.

Not a binary. A platform.

Extend flexfetch without forking it. Three tiers of extensibility, configured in your own files.

Custom modules

Define a [custom] section in ~/.config/flexfetch/config.toml — each entry is a module name plus the shell command that produces its value.

  • one entry = one module
  • appears in output automatically
  • no recompiles

Tera templates

Write your own template with loops and conditionals for full control over the layout, per-module colors, and icon set.

  • Jinja2-style syntax
  • per-module color/icon variables
  • drop-in .tera files

Export anywhere

flexfetch --export renders the same fetch to SVG, PNG, HTML, Markdown, CSV, or Prometheus — for badges, CI, dashboards, and docs.

  • machine formats included
  • GitHub Actions annotations
  • one command, many outputs
